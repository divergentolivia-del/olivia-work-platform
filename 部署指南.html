📱 手机部署指南

Olivia Work Platform v10.6 · 一次部署，永久使用

🎯 目标

把工作台部署到 Cloudflare Pages（完全免费）
手机随时随地打开，不依赖任何电脑，不需要买服务器

为什么选 Cloudflare Pages？

✅ 完全免费，永远免费，不需要绑信用卡

✅ 不需要买服务器，纯静态托管

✅ 国内访问速度快（有 CDN 节点）

✅ 没有冷启动，打开秒响应

✅ AI 功能通过 TRAE 桥接模式正常使用（零配置）

1

注册 GitHub 账号

GitHub 是代码托管平台，你的项目代码放在这里，Cloudflare 会自动从 GitHub 拉取代码部署。

  1. 打开 github.com
  2. 点右上角 "Sign up"，用邮箱注册（免费的）
  3. 已有账号的直接 "Sign in"
💡 如果已有 GitHub 账号，跳过这步。
2

在 GitHub 上创建项目仓库

  1. 登录后，点右上角 "+" → "New repository"
  2. Repository name 填：olivia-work-platform
  3. 选 "Public"（公开，免费版必须公开）
  4. 勾选 "Add a README file"
  5. 点 "Create repository"
3

上传项目文件到 GitHub

在你的仓库页面：

  1. 点 "Add file" → "Upload files"
  2. 把 zip 解压后的所有文件拖进去
  3. 需要上传的核心文件：index.html, app.js, styles.css, static-fallback.js, template-data.js, data.js, my-data.js, sw.js, manifest.json, icon.svg, package.json，以及 assets 文件夹
  4. 以点号开头的文件（.gitignore, .env.example）如果传不了就跳过，不影响使用
  5. 等上传完，页面底部点 "Commit changes"
💡 如果文件较多，可能需要分几次上传。每次最多约 100 个文件。
4

注册 Cloudflare 账号

  1. 打开 dash.cloudflare.com/sign-up
  2. 用邮箱注册（免费的，不需要绑卡）
  3. 已有账号的直接登录
💡 Cloudflare 注册完全免费，不需要信用卡，不会产生任何费用。
5

在 Cloudflare Pages 创建项目

  1. 登录后，左侧菜单找到 "Workers & Pages"，点进去
  2. 点 "Create" 按钮
  3. 选 "Pages" 标签页
  4. 点 "Connect to Git"
  5. 授权 Cloudflare 访问你的 GitHub（点 "Authorize Cloudflare"）
  6. 选择你刚才创建的 olivia-work-platform 仓库
  7. 点 "Begin setup"
6

配置部署参数

在设置页面填以下内容：

  1. Project name：olivia-work-platform（随意起名）
  2. Production branch：main（或 master，看你仓库默认分支）
  3. Framework preset：选 None
  4. Build command：留空（不需要构建）
  5. Build output directory：留空或填 /（根目录就是输出）
💡 关键：Build command 和 Build output directory 都留空！因为你的项目是纯静态的，不需要编译。

填完后点 "Save and Deploy"。

7

等待部署完成

Cloudflare 会自动拉取你的代码并部署。通常 1-2 分钟就完成。

部署成功后，你会看到一个网址，格式类似：

https://olivia-work-platform.pages.dev
✅ 这就是你的公网网址！永远有效，不用管电脑开不开机。
8

手机打开并添加到桌面

  1. 把 xxx.pages.dev 网址发到手机（微信文件传输助手）
  2. 用手机浏览器打开（Safari 或 Chrome，不要在微信里直接打开）
  3. iPhone（Safari）：点底部分享按钮 → "添加到主屏幕" → 改名 → 添加
  4. 安卓（Chrome）：点右上角三个点 → "添加到主屏幕" → 确认

✅ 完成！

桌面上的图标点开就是完整工作台
全屏运行，有离线缓存，像 App 一样
随时随地打开，不依赖任何电脑，永久免费

🤖 关于 AI 功能

部署后所有 AI 功能都能用，采用 TRAE 桥接模式：

  • 点击 AI 功能后，系统会生成一段可复制的指令
  • 复制指令 → 粘贴到 TRAE 中执行 → 得到 AI 结果
  • 无需配置任何 API Key，零门槛使用
💡 如果你以后想让 AI 直接出结果（不用复制粘贴），可以在 Cloudflare Pages 项目设置 → Environment Variables 中配置 API Key（如 DEEPSEEK_API_KEY），然后重新部署。但需要额外部署一个后端服务，目前先用桥接模式即可。

❓ 常见问题

部署后网址打不开？

检查 Cloudflare Pages 部署状态是否为 Success。如果失败，检查仓库里是否有 index.html 文件在根目录。

Cloudflare 会收费吗？

不会。Cloudflare Pages 免费版包含无限带宽、500 次构建/月，个人使用完全够用，不需要绑信用卡。

手机上的数据和电脑上一样吗？

不一样。数据存在手机浏览器本地（localStorage），和电脑端是独立的。如果需要同步，用设置 → 数据备份 → 导出，再在另一端导入。

以后改了代码怎么更新？

把新代码上传到 GitHub 仓库（覆盖旧文件），Cloudflare Pages 会自动重新部署。不用再做任何其他操作。

国内访问速度怎么样？

Cloudflare 在国内有 CDN 节点，访问速度很快。比 Render、Vercel 都快，也不会被墙。
