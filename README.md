# Olivia Work Platform · 个人成长全链路平台

## 快速开始

将 `OliviaWorkPlantform` 文件夹中的所有文件下载到本地同一个目录。

如果只使用信息管理功能，可以双击 `index.html` 打开。

如果要使用 AI 助手，需要在当前文件夹运行：

```bash
npm start
```

然后打开：

```text
http://localhost:3000
```

所有个人数据都保存在你的本地文件或浏览器本地存储中。AI API Key 保存在本地 `.env` 文件里，不会写进前端页面。

### AI 能力调用方案

v8.0 采用"TRAE 桥接为主 + 免费模型兜底"方案：

- 在 TRAE 环境中：所有 AI 能力通过 TRAE 当前会话代理执行，零配置
- 在纯本地环境中：通过 `.env` 配置的模型 API 调用（支持千问、DeepSeek、Kimi、Claude、OpenAI 等）
- TRAE 协作模式：复制结构化指令给 TRAE → 粘贴返回结果回工作台

## 各中心功能详情

### 首页仪表盘

- 今日概览卡片：待办任务数、学习时长、饮水量、AI对话次数、专注番茄数
- 数据看板：本周完成率趋势（CSS柱状图）、目标进度（环形图）
- 时间线：今日重要事项时间轴
- 快捷入口：常用功能一键直达

### 项目管理中心

- 合集管理：按项目/主题分组
- 任务看板：待办/进行中/已完成/已归档四列，支持"派AI"标记
- 视图切换：看板视图 / 卡片视图
- 日历规划：日程安排、deadline提醒
- 日报生成：AI自动汇总当日工作产出

### AI能力中心

- AI对话：多轮对话、上下文记忆、专业领域问答
- 资料搜集：输入主题→AI联网搜索→结构化输出（摘要/要点/来源/建议）
- AI写作：汇报材料、邮件、PRD文档一键生成
- PM知识库：模型认知、Prompt工程、评估体系、案例库
- Skills技能库：可复用AI技能、GitHub社区搜索

### 学习成长中心

- 学习任务：待办清单、优先级、截止日期、标签
- 专注计时（番茄钟）：
  - 环形进度条可视化倒计时
  - 模式：25+5 / 45+15 / 52+17
  - 关联任务、白噪音开关
  - 专注数据统计：日/周/月趋势
- 知识笔记（PARA体系）：
  - Projects（项目）：有明确截止日期的学习项目
  - Areas（领域）：持续维护的知识领域
  - Resources（资源）：兴趣参考材料
  - Archives（归档）：已结束的内容
  - 标签分类、搜索
- 目标管理（OKR）：
  - Objective + Key Results
  - 信心指数标记
  - 进度追踪
  - 季度/月度周期管理
- 成就系统：完成目标解锁徽章

### 英语学习

- 背单词（百词斩模式）：
  - 单词卡片翻面记忆
  - 艾宾浩斯复习曲线
  - 场景词库：亲子/商务/托业

  - 泛听模式：后台播放

### 读书管理

- 书架：在读/想读/已读三栏分类
- 阅读进度：百分比追踪
- 读书笔记：划线摘录、心得感悟、标签
- 阅读统计：本月阅读量、累计时长

### 健康生活中心

- 每日记录：日记、心情、感悟

## 配置 API Key

复制 `.env.example` 为 `.env`，然后填入你已有的平台 Key。至少填一个模型 Key 才能生成内容。

```bash
cp .env.example .env
```

推荐先填：

```text
DEEPSEEK_API_KEY=
ARK_API_KEY=
DASHSCOPE_API_KEY=
MOONSHOT_API_KEY=
ANTHROPIC_API_KEY=
OPENAI_API_KEY=
```

`GITHUB_TOKEN` 可不填；不填也能搜索 GitHub，但额度更低。
